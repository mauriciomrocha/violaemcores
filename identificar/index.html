Identificar acorde

Marque as casas ou digite a forma: o nome, as notas e onde ela aparece

X = par não tocado · 0 = solto · número = casa. Ex.: X 4 3 5 4.

Braço

Toque numa casa para marcar o par ali; toque de novo para não tocar o par. Antes da pestana do instrumento = par solto.
